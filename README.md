**Files Caelumite downloads at runtime.** They can be added to or edited without an app update.

This branch is Caelumite's copy of the
[Amethyst Mod Manager](https://github.com/ChrisDKN/Amethyst-Mod-Manager)
`Resources` branch. Upstream changes are merged in with
`scripts/sync-upstream.sh` on `main`. Review any plugin code before pushing:
Caelumite runs it.

- **Custom Handlers** - Game handlers created in the define custom game menu.
- **Localisation** - Language files
- **Plugins** - External wizard tools (Not currently used in v2)
- **Profiles** - Pre made modlists
- **Synthesis** - NuGet config for Synthesis

Upstream's GitHub Actions workflows and Crowdin config are not included.
